Settings protection

Require confirmation for changes within the extension. The Chrome user can still remove the extension or change its data using developer tools.

Use 8–200 characters. Leave both fields blank to keep the current credential. A phrase is shown during confirmation. A password is never shown and only a verification value is stored. Forgotten passwords cannot be reset by email.

Protect these settings

Changing or turning off protection requires valid authorization.

Content filters

One rule per line. Channels: exact name, @handle, ID or URL. Videos: part of a title, ID or URL. Comments and posts: part of the text, ID or URL. Text matching ignores case; channel IDs are case-sensitive. The video you are watching is not blocked. On watch pages, filters apply to recommendations and comments.

Regular expressions: /pattern/i with the flags i, m, s, u. Literals, character classes, dots, anchors and up to four ? quantifiers are supported. Groups, |, *, +, {…} and backreferences are not allowed, so a rule cannot freeze the page.

Player

If the preferred quality is unavailable, an available quality is used. Turning this off restores automatic quality selection by YouTube.

Experimental: seeking is attempted only when an ad is detected and its video supports seeking. Ads embedded in the main stream and ads that prevent seeking may remain. Native controls and quality selection depend on the current YouTube player.
